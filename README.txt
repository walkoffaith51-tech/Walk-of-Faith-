WALK OF FAITH APP - FIRST WORKING VERSION

Open index.html to preview the app.
Features:
- Walk of Faith logo and Minister Roshelle Crummie branding
- Devotional Message
- Bible Quiz of the Day
- Message Minister Crummie via walkoffaith51@gmail.com
- PIN-protected private sermon organizer stored on the device
- Installable web-app files (PWA)

Important: This first version opens the user's email app to send messages. For true in-app message delivery, cloud accounts, push notifications, and syncing sermons across devices, a hosted backend must be connected.
